# V21：LightGlue 后 F-MAGSAC++ 的受控对照

已完成39对、156次原生 PnP 调用。**F-MAGSAC++ 是更强的离线候选：准确位姿从 V19
的15/39增加到17/39，新增退化从7对减少到5对，平移误差P95从15.40cm降到11.38cm。**
但等量随机子集23达到18/39、3对退化，且 F 仍损失原八对获益中的两对，当前不默认启用。

## 完整比较

准确要求 nearest 与 interpolated 两种 GT 对齐都满足3cm/2°。返回结果包括精确原始
位姿回退；新增退化以原始准确位姿为参照。所有39对始终保留。

F 相对 V19 新增准确：xyz24-25、desk22-24、room141-143、room142-143；失去准确：
xyz24-26、desk21-24。总计四对收益、两对损失。八个修复原始错误的结果中，六个来自
V19 已有获益，另外两个是本次新获益。

F 在各场景的准确数为 xyz4/6、desk2/6、room5/6、teddy6/21。各组均有相同两对原生
拒绝：room141-144、142-144。156个新执行中共八次精确 raw 回退，无验证失败、进程
失败、超时或OOM。F/H 各39次模型估计均返回有效输出；模型成功本身不计为准确位姿。

V20 的未补偿/补偿共同子集分别为16/39、4对退化、保留4/8，以及16/39、3对退化、
保留3/8。F 多一个准确结果、保留更多原获益，但新增退化仍多于 V20 补偿组；这是一组
真实取舍，不是所有指标的统一改进。

## 按冻结方案实施

新增入口 `python/run_magsac_comparison.py`，分 `verify` 与 `fit` 命令，另复用原独立
评价器。缓存、冻结方案、V19 study、原生二进制与全新输出路径均显式传入。

1. 读取 V19 全部二维匹配和原 RootSIFT 像素坐标，不重新匹配、不读取深度时间补偿。
2. F 在全部二维匹配上用 `USAC_MAGSAC`、3px、confidence0.999、maxIters10000估计。
3. F掩码与 V19 原源端深度有效行相交；保持原特征 ID、目标像素和索引顺序。
4. 三个控制从 V19 原深度有效行均匀无放回选择相同数量，NumPy种子17、23、41，
   再按原索引排序。39对均核对了四组行数相等。
5. 使用原始深度、历史内参、原生 PnP二进制及配置。requested seed仍为17。

H 使用相同固定参数单独估计并记录支持和残差，始终只作诊断：不选模型、不门控输入、
不恢复相机位姿，也不按不可直接比较的 F/H 支持比例决定哪个模型“正确”。

本地二维验证是 OpenCV5.0.0，单线程，requested全局seed17；原生PnP仍为既有OpenCV4.6
二进制。没有声称设置全局seed保证改变各估计器内部随机状态。只运行了一个固定F/H
配置，没有按结果调整阈值。

原源深度有效对应11455个，F后为10797个，移除658个（5.74%）。源端3x3深度规则、
5000单位/m、640x480坐标、历史内参均不变。没有叠加 V20 时间补偿、MAGSAC位姿后端、
BA或在线跟踪。验证、拟合均不读取GT，输入和拟合封存后才运行既有评价器。

## 成本与必要验证

39次F估计合计0.0527s，39次诊断H合计0.0351s；验证阶段含缓存读取和结果写入共
0.547s，峰值RSS126.01MiB。156个原生worker阶段36.45s，包含逐worker Python启动、
文件和进程开销。没有新LightGlue推理、训练或GPU计算。这些是本机单次阶段测时，
不能等同于完整在线SLAM吞吐。

仅运行三项新适配检查：完整二维掩码正确映射原深度行、等量子集可复现并保持ID/顺序、
非法模型/掩码拒绝；均通过。未重复全量回归，没有审查或改写既有未提交文件。

```sh
python python/run_magsac_comparison.py verify \
  --plan results/magsac_verification_plan.json \
  --baseline-study "$V19_STUDY" --matching "$V19_MATCHING" \
  --output "$NEW_VERIFICATION"
python python/run_magsac_comparison.py fit \
  --verification "$NEW_VERIFICATION" --baseline-study "$V19_STUDY" \
  --native-binary "$NATIVE_PNP" --output "$NEW_STUDY"
python python/run_camera_pnp_comparison.py evaluate \
  --study "$NEW_STUDY" --sources "$EVALUATION_SOURCES_JSON" \
  --output "$NEW_EVALUATION"
```
