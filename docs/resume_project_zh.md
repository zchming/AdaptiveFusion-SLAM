# AdaptiveFusion-SLAM 简历项目描述

## 推荐简历版本

**AdaptiveFusion-SLAM：面向视觉退化场景的风险自适应 RGB-D SLAM 系统**  
*C++17 / CMake / Eigen3 / OpenCV / Ceres / TUM RGB-D*

- 从零实现研究型 RGB-D SLAM 原型，打通 RGB-D 时间同步、ORB 特征、LK
  光流、3D-2D 对应、PnP-RANSAC 位姿估计、关键帧/地图点管理、Ceres 局部
  Bundle Adjustment、TUM 轨迹输出及 ATE/RPE 评估全流程。
- 设计由 PnP 内点率、重投影误差、光流前后向误差、特征覆盖率、视差和
  有效深度率组成的多帧几何健康序列，使用逻辑回归预测未来 3 帧的跟踪
  失效风险，并以 low/medium/high/critical 四级策略主动调整特征匹配、关键帧
  插入和地图写入。
- 在 TUM `rgbd_dataset_freiburg1_xyz` 的 792 个同步帧上实现 100% 跟踪成功；
  自适应模式在 ATE 基本持平（0.062081 m → 0.062442 m）的情况下，将关键帧
  减少 19.3%（114 → 92）、地图点减少 19.8%（79,790 → 63,983）、局部 BA
  次数减少 20.4%（113 → 90），平均帧耗时降低 20.2%（60.07 ms →
  47.91 ms），吞吐率提升 25.4%（16.65 FPS → 20.87 FPS）。
- 构建运动模糊、低照度、遮挡、高斯噪声和周期性丢帧五类确定性退化仿真；
  在丢帧实验中记录 20 个失效帧和 19 次单帧恢复，自适应策略将地图点减少
  10.9%（12,015 → 10,710）、P95 帧耗时降低 19.0%（120.55 ms →
  97.68 ms），ATE 降低 3.85%（0.024499 m → 0.023557 m）。
- 建立可复现实验链路，自动输出健康状态、风险、未来失效标签、轨迹、运行时
  和地图统计 CSV；Release 模式下 16 项单元/集成测试全部通过。

## 一行精简版本

从零实现带多帧失效预测与风险自适应地图更新的 RGB-D SLAM；在 TUM
Freiburg1 XYZ 上保持 100% 跟踪成功和基本持平的 ATE，同时减少 19.8% 地图
点与 20.2% 平均帧耗时，将运行速度从 16.65 FPS 提升至 20.87 FPS。

## 面试时应准确说明的边界

当前结果证明了完整系统、风险控制和降低地图/计算开销的有效性。当前风险
模型由受控合成序列训练，尚不能据此声称在多数据集上提高轨迹精度；真实
序列标定、回环检测、重定位和实机部署属于后续研究。
